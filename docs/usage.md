# Usage

```python
import nlp_dashboard
```

Each module is self-contained; see docstrings for the API:

- `nlp_dashboard.dashboard` — TUI dashboard logic
- `nlp_dashboard.panels` — Panel implementations for tokenization and analysis
- `nlp_dashboard.sparklines` — Sparkline visualizations for metrics
- `nlp_dashboard.tokenizer` — Text tokenization module
- `nlp_dashboard.analysis` — Text analysis module with metrics calculation
- `nlp_dashboard.main` — Entry point and application setup
